OurLapse Privacy Policy

Last updated: 2026-09-02

OurLapse is a small-group video log app. Users can create or join rooms, record short videos, share them with room members, send chat messages, and manage room participation.

Information We Collect

  • Profile name and profile image
  • Room participation information, including room name, invite code, member list, and membership status
  • Videos uploaded by the user
  • Chat messages sent by the user
  • Reports, block records, and moderation-related actions
  • Device-local app data required to keep the app state

The app requests camera and microphone access to record videos. It may request photo or media access when the user chooses a profile image, imports media, or saves exported videos.

How We Use Information

  • Create and manage small-group rooms
  • Show videos and messages to members of the same room
  • Sync room, chat, and video data between devices
  • Support safety features such as reporting and blocking
  • Save or export user-created video content when requested

Sharing

Videos and messages are designed to be visible only to members of the room where they were posted. We do not sell personal information.

Data may be processed by Supabase, which provides backend authentication, database, storage, and realtime synchronization for the app.

Data Deletion

Users can delete local app data from the app settings. When server connection is available, the app also attempts to delete the user's remote profile data, uploaded videos, chat messages, reports, blocks, and room participation records.

Data Retention

Local data remains on the user's device until the user deletes it or uninstalls the app. Server data remains until deleted by the user or by backend cleanup rules.

Children's Privacy

OurLapse is not intended for children under 13. Users should not upload content or personal information from children without proper permission.

Security

We use Supabase authentication, database policies, and storage access rules to limit access to room data. No system can guarantee perfect security, so users should avoid uploading sensitive information.
